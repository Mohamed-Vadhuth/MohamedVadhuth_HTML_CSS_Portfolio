---

## 💻 Responsive Implementation

- **CSS Flexbox:** Applied to Header Navigation, Hero CTA buttons, Contact cards, and Footer.
- **CSS Grid:** Applied to the About layout, Skills cards (`repeat(auto-fit, minmax(200px, 1fr))`), and Projects showcase (`repeat(auto-fit, minmax(320px, 1fr))`).
- **Mobile Media Query (`@media (max-width: 768px)`):** Stacks multi-column grids and flex containers cleanly to avoid horizontal scrollbars on mobile phones and tablets.
